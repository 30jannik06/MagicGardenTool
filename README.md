# Magic Garden Tools

Drei kleine Browser-Userscripts für [magicgarden.gg](https://magicgarden.gg) — laufen über [Tampermonkey](https://www.tampermonkey.net/).

## Scripts

### 🌱 Co-Pilot (`mg-copilot.user.js`)
Übersicht über deine Beete: Erntetimer pro Feld, Saatgut-ROI-Rechner und Session-Stats (Coins/Stunde, Idle-Zeit). Draggable HUD mit mehreren Tabs.

### 🛒 Auto-Buy (`mg-autobuy.user.js`)
Kauft ausgewählte Shop-Items automatisch, sobald sie bei einem Restock verfügbar sind — nützlich für limitierte Items, die man sonst leicht verpasst, wenn man nicht am PC ist. Items werden per Checkbox pro Shop-Tab ausgewählt.

### 🌦️ Weather Forecast (`mg-weather-forecast.user.js`)
Zeigt das aktuell laufende Wetter-Event sowie die bekannten kommenden Events (inkl. Mond-Events) mit Countdown und Uhrzeit.

## Installation

Am einfachsten: [Tampermonkey](https://www.tampermonkey.net/) installieren, dann einen der folgenden Links öffnen — Tampermonkey erkennt das Script automatisch und bietet die Installation an (danach auch automatische Updates):

- [mg-copilot.user.js](https://raw.githubusercontent.com/30jannik06/MagicGardenTool/main/mg-copilot.user.js)
- [mg-autobuy.user.js](https://raw.githubusercontent.com/30jannik06/MagicGardenTool/main/mg-autobuy.user.js)
- [mg-weather-forecast.user.js](https://raw.githubusercontent.com/30jannik06/MagicGardenTool/main/mg-weather-forecast.user.js)

Alle drei sind unabhängig voneinander, können einzeln oder zusammen installiert sein. Danach magicgarden.gg öffnen — die Panels erscheinen automatisch.

## Rechtlicher Hinweis

magicgarden.gg hat laut Aussage des Server-Betreibers im offiziellen Discord eine Modding/Automation-Policy, die Scripts und Automatisierung grundsätzlich erlaubt. Nutzung auf eigenes Risiko — bei Unsicherheit im offiziellen Discord nachfragen.
